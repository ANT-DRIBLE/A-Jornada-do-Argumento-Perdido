# ⚔️ Redação Quest

### A Jornada do Argumento Perdido

Redação Quest é um jogo educativo no estilo RPG desenvolvido para ensinar a estrutura da dissertação argumentativa de maneira interativa e divertida.

## 🎮 Funcionalidades

- Criação de personagem.
- Sistema de experiência (XP).
- Níveis e pontuação.
- Quatro fases educativas.
- Desafios de múltipla escolha.
- Batalha final com produção textual.
- Tela de vitória.
- Layout adaptável para celular e computador.

## 📚 Conteúdos trabalhados

1. Introdução e tese.
2. Desenvolvimento e argumentação.
3. Repertório sociocultural.
4. Conclusão e proposta de intervenção.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo index.html no navegador.
4. Comece sua aventura!

## 🎯 Objetivo

Ensinar a estrutura da redação dissertativo-argumentativa por meio de desafios de RPG.

Desenvolvido como projeto educativo.
